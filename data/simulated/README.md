# Simulated data

Everything in this directory is algorithmically generated for local development
and presentation rehearsal. These files are not source evidence, ground truth,
model-training data, operational records, or official-report inputs.

Each scenario must carry explicit `simulated` status and false eligibility flags.
Generated artifacts must never be moved into `data/raw/` or into a validated
dataset manifest.

The `sp021-195` scenario is documented in
[`docs/data-quality/simulated-mowing-timeseries.md`](../../docs/data-quality/simulated-mowing-timeseries.md).
