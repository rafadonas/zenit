# Sprint 4 — mobile screen evidence

Screens of the real ZENIT Flutter app rendered by the GOV-001 capture harness
(`apps/mobile/tool/gov_001_capture_test.dart`) in GitHub Actions run
[39285234887](https://github.com/rafadonas/zenit/actions/runs/39285234887),
viewport 390 × 844.

- Data status: **synthetic test fixtures** (in-memory gateway and vault). No real
  field data, GPS, photos or measurements. Not eligible for training, official
  reporting or field authorization.
- Some images are cropped (not edited) to remove buttons whose labels render as
  placeholder boxes under the Flutter test font; this is a test-environment
  artifact, not an app defect.
